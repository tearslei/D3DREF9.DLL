# d3dref9自治.dll

这是单 DLL 的输入宏、Home 面板与瞬狙时序骨架，运行时不读取或启动 `程序自动化按键.ahk`。

## 当前按键

| 按键 | 行为 |
|---|---|
| `Home` | 显示/隐藏左上角 45% 透明面板 |
| `L` | 仅切换开枪模式：普通 ↔ 瞬狙 |
| `P` | 普通模式瞄准位置循环：颈部 → 头部 → 胸部 |
| `左Alt+Z` | 自动瞄准 + 自动开枪总开关（默认关） |
| `左Alt+Z` | 自动瞄准 + 自动开枪总开关（默认关） |
| `O` | 键盘宏总开关 |
| `鼠标左键 / 鼠标右键` | 瞬狙模式触发磁性自瞄与瞄准射击 |
| `-` | 未注册，不退出、不发送释放序列 |

## 宏迁移

`src/macro_engine.cpp` 已按 AHK 原始 Sleep、循环上限、MouseMove 位移和释放顺序移植 11 个动作。按键由 `InputRouter` 统一标记为 `MACRO` 来源，停止时只释放 DLL 自己注入的按键。

## 瞬狙冷却

```text
R1=random(0..100); R2=random(0..100)
右键↓ → R1 → 左键↓ → R2 → 3↓↑ → 35ms → 1↓↑
冷却=1565-R1-R2
总轮次=1600ms
```

普通模式 P 键默认颈部；瞬狙候选为头部/颈部/胸部/中腰/臀部并自动选离准心最近部位。

瞬狙期间仅暂时关闭 `自动瞄准+自动开枪` 状态；`左Alt+Z` 是独立总开关，冷却结束仅在用户未改动总开关时恢复。

## 当前未实现部分

游戏内生命、透视、后坐力等功能的实际地址/调用约定尚未写入本工程；`FeatureManager` 已提供统一状态和面板接口，后续将把已确认的客户端偏移接入对应 handler。替换原 D3D9 代理前需先导出并转发原 DLL 的 D3D9 导出函数，否则客户端可能无法创建渲染设备。
