# d3dref9自治.dll

当前版本是 CrossFire 1.1.85.7 Win32/x86 的 C++17 DLL，包含输入路由、Home 面板、键盘宏、目标筛选、普通自瞄/自动开火和瞬狙状态机。

## 当前按键

| 按键 | 行为 |
|---|---|
| `F9+H` | 显示/隐藏左上角约 45% 透明、320×420 面板（原 `Home` 已取消） |
| `F7+5` | 旧版不掉血开关；启动时默认开启，功能隐藏在面板之外 |
| `L` | 普通模式 ↔ 瞬狙模式 |
| `F10+6` | 普通瞄准位置循环：颈部 → 头部 → 胸部 |
| `左Alt+Z` | 自瞄/自动开火总开关 |
| 物理鼠标左键（普通模式） | 按住时才运行普通自瞄和自动开火 |
| 物理鼠标右键（瞬狙模式） | 按住持续触发；松开立即停止 |
| `[` | 暂停/恢复键盘宏 |
| `-` | 取消宏并释放 DLL 模拟按键 |

已删除并不会再触发：`Alt+1`、`F6` 瞬狙、`P` 部位切换。瞬狙无有效目标时不发送鼠标序列。

## 普通模式开火

- 总开关打开且物理左键按住时，筛选存活敌人、敌我关系、准心附近目标和障碍射线。
- 目标有效后写入瞄准角度，并以约 130 ms 间隔发送一次 `LEFTDOWN → LEFTUP`。
- 每次是独立点击，不会持续按住左键。

## 瞬狙模式

- 仅物理右键触发；按住持续运行，松开立即停止并释放 DLL 自己的按键。
- 触发前锁定准心最近有效部位：头、颈、胸、中腰、臀部。
- 时序参数在 `config\\d3dref9自治.ini` 的 `[instant_sniper]` 中可调：开镜延迟、左键保持、松镜延迟、恢复和冷却。
- 冷却期间暂停普通自瞄/自动开火，结束后仅恢复触发前原本开启状态。

## 面板和自动启动

- 面板隐藏时功能继续运行，Home 不重置状态。
- 两键优化在 DLL 加载约 150 秒后启动；房间保持、旧版不掉血和摔不掉血由启动处理器自动开启。
- 旧版不掉血可用 `F7+5` 切换；摔不掉血可用 `F9+V` 切换。两项均不显示在面板。
- 无限背包仍保持删除。
- 宏动作按 AHK 原始时序迁移到 DLL，不读取或覆盖 `程序自动化按键.ahk`。
