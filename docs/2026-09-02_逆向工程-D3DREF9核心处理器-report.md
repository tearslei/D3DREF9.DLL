# 2026-09-02 逆向工程-D3DREF9 核心处理器阶段报告

## 摘要

本报告记录自治 `D3DREF9.DLL` 的当前实现和未完成门槛。构建和 ordinal 1 加载已验证；实体坐标、骨骼、世界矩阵、屏幕投影、DrawCall 关联及其上层处理器尚未完成实机验证，因此当前不能称为“完整成品”。

## 已观察事实

1. Win32/x86 直接替换 DLL 已成功构建。
2. 客户端目录中的 DLL 已被进程加载。
3. 运行日志出现 `event=installed`、`event=device_captured`。
4. 最近实体 CSV 只有大厅/退出阶段样本：`local_ok=0`、`pos_valid=0`、`bone_mask=0`。
5. 已有实体根、槽位、存活字段和坐标 relay 候选，但均需对局生命周期验证。

## 验证流程

```text
正常启动客户端
  → 进入实际地图
  → 保持目标可见 30 秒
  → 退出客户端
  → 检查 entity/render CSV 与日志
  → 通过 Gate A/B/C
  → 接入目标筛选和处理器
  → 单项开关回归
```

## 验收标准

- 实体：至少两个非本地对象连续 10 个采样窗口；
- 骨骼：五部位至少两个有效，姿态变化可重复；
- 矩阵：相机旋转/目标移动均产生可解释变化；
- 投影：`screen_valid=1` 且坐标与画面位置一致；
- 绘制：同一对象出现/消失与 DrawCall 资源变化同步；
- 开关：每项关闭后状态、字节和线程行为恢复基线；
- 异常：无持续按键、无 B 键循环、无启动闪退。

## 当前结论

当前阶段为“兼容壳 + 框架 + 候选适配器”，不是完整成品。下一次有效对局采样是进入真实处理器接线的必要 Gate。
