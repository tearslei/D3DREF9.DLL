# 2026-09-07 系统设置与 ERS 回滚记录

## 现象

CF 登录阶段弹出 `CROSS FIRE ERROR / Do you want to report to ERS system?`。

## 排查结论

- 未发现本机存在 CrossFire 专用 IFEO、AppInit DLL、服务、计划任务或 D3D9 sidecar 注入项。
- `HKLM\...\Windows\AppInit_DLLs` 为空，`LoadAppInit_DLLs=0`。
- `crossfire.exe` 相关计划任务不存在；`TESMON` 服务不存在。
- WinHTTP 代理为 Direct access；电源方案为“平衡”。
- 失败构建日志包含 `event=font_hook_installed` 和 `event=device_captured`。这些来自 `D3DXCreateFontA` 入口改写和 D3D9 设备虚表替换，发生在登录渲染初始化阶段，是最直接的变更点。

## 已执行恢复

1. 将失败客户端 DLL 备份为 `D3DREF9.ers-20260907-011240.bak`。
2. 恢复已验证可启动的 `D3DREF9.before-aim-20260907-003358.bak`，SHA256=`1AB23BF7C1FB81E2E63C22DD86002B56A1924FE345D6BB34BD7E4F5A814A8F7A`。
3. 源码 `src/render_adapter.cpp` 的 `RenderAdapter::Start()` 改为被动返回 `false`，不再安装字体 Hook/设备 VTable Hook。
4. 重新构建 direct DLL（x86，ordinal 1 保留）并部署到客户端，当前 SHA256=`3B493EFB83987D9690E7468FD9C9DDE66A84D6392505E58242C679ACEC031867`。
5. 部署前 DLL 保存为 `D3DREF9.DLL.before-disabled-render-20260907.bak`。

- 当前客户端 DLL 与源码同步；未修改服务器、RB001.REZ、SQL/LiteSQL 或系统网络/电源配置。
