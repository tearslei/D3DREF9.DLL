# D3DREF9 核心处理器实现技术文档

## 1. 目标与范围

本文档定义当前 CrossFire 1.1.85.7（Win32/x86）自治 DLL 的五阶段实现、证据门槛和回归方法：

1. 实际对局采集实体坐标与骨骼；
2. 验证世界矩阵和屏幕投影；
3. 关联 D3D9 绘制调用；
4. 接入目标筛选、人物透视、自瞄和自动开枪；
5. 逐项开启/关闭并确认状态恢复。

## 3. 五阶段实施流程

### 阶段一：实体和骨骼采集

**输入**：正常启动的客户端、实际地图、可见目标。

**采样要求**：保持目标可见至少 30 秒；不使用暂停式启动脚本；采样器只读进程内存。

**输出**：`%TEMP%\\d3dref9_entities.csv`、`%TEMP%\\d3dref9_entity_hook.log`。

**通过条件**：

- `local_ok=1` 且 `local_addr` 连续稳定；
- 至少一个 `entity_addr` 连续出现；
- `alive` 随目标状态变化；
- `coord_table != 0`；
- `pos_valid=1`；
- 五个候选骨骼点中至少两个 `bone_mask` 位有效；
- 关闭功能后指针和读取线程仍稳定。

### 阶段二：世界矩阵与屏幕投影

从 D3D9 设备读取 `D3DTS_VIEW`、`D3DTS_PROJECTION` 和 viewport。对同一目标执行：

1. 视角水平旋转；
2. 视角垂直旋转；
3. 目标移动；
4. 分辨率或窗口尺寸变化。

**通过条件**：矩阵随相机变化，投影点随目标移动，`screen_valid=1`，坐标落在 viewport 内，且重复采样误差可解释。

### 阶段三：D3D9 绘制关联

设备链：

```text
D3DXCreateFontA → IDirect3DDevice9 → vtable
                                   ├─ Present(17)
                                   ├─ EndScene(42)
                                   └─ DrawIndexedPrimitive(82)
```

记录每帧调用计数、stride、primitive 数、纹理/索引资源和投影目标。不得把单个 DrawCall 直接认定为人物模型；必须通过对象出现/消失和屏幕位置变化进行交叉验证。

### 阶段四：目标筛选、透视、自瞄、自动开枪

目标筛选顺序：

1. 丢弃空指针、死亡对象和本地对象；
2. 按模式判断敌我阵营；
3. 要求五个骨骼点至少一个成功投影，并用五点 AABB 作为身体轮廓代理；
4. 使用 TCII 源码的“微型”范围值 `16`（半宽/半高为 `viewport/(1+16)`），也可用 `micro_radius_px` 指定实际像素半径；
5. 任意身体骨骼像素进入范围并通过障碍射线后才成为候选；射线不可用、指针为空或异常时 fail-closed；
6. 按准心到身体像素的最短距离排序，世界距离作平局条件，并保持短暂目标锁定；
6. 普通模式使用 P 键选择颈部/头部/胸部；
7. 瞬狙模式在头部、颈部、胸部、中腰、臀部中选择距离准心最近点；
8. 自动开枪只在目标有效且总开关开启时触发。

瞬狙时序保持：`右击→左击 100ms`、`左击→3 100ms`、`3→1 35ms`、`1 后冷却 1350ms`，总目标 1600ms。冷却期间只暂停自瞄和自动开枪，不暂停宏。

### 阶段五：逐项回归

每项功能执行固定序列：

```text
关闭基线 → 单独开启 → 实际触发 → 观察结果 → 关闭 → 检查恢复 → 记录日志
```

必须保留：开关前字节、启用字节、关闭恢复字节、调用结果、崩溃/异常信息和 CSV 快照。

## 5. 证据分级

- **L0**：单次变化；
- **L1**：多次重复出现；
- **L2**：输入或场景变化后稳定变化；
- **L3**：可逆开启/关闭，结果同步变化；
- **L4**：跨地图/生命周期一致；
- **L5**：内存、调用链、渲染和行为独立交叉验证。

只有阶段一至三达到 L3/L4，阶段四才能进入真实处理器接线；阶段五完成后才可标记为成品候选。

## 6. 本次自瞄筛选改动

源码位置：`src/entity_adapter.cpp`、`src/game_handlers.cpp`、`include/entity_adapter.h`、`include/game_handlers.h`。

- `EntitySnapshot` 新增五个骨骼的屏幕坐标、屏幕有效位图和身体 AABB；
- `AcquireTarget()` 普通自瞄和瞬狙共用同一套微型范围、身体相交、可见性和最近目标筛选；
- 普通模式仍由 `P` 选择颈部/头部/胸部，瞬狙则从五个有效骨点中选择准心最近点；
- `IsVisible()` 改为 fail-closed；旧实现的“地址缺失即 true”已移除；
- 新增 `[aim]` 配置：`micro_range_divisor`、`micro_radius_px`、`body_padding_px`、`lock_hold_ms`、`switch_margin_px`、`auto_fire_interval_ms`、`visibility_required`、`visibility_fail_closed`；
- CSV 诊断新增 `body_*` 和 `bone_screen_mask` 字段，便于实机确认筛选资格。
